# 책을 올바른 순서로 제자리에!

책 10권을 북카트에서 집어 서가에 꽂는 모바일 웹 게임입니다. 서버 API, 로그인, 외부 폰트, 별도 빌드 또는 패키지 설치가 필요하지 않습니다.

## 저장소 파일

`index.html`이 저장소 최상위에 있습니다. 이 폴더의 내용 전체를 GitHub Desktop으로 관리하는 저장소에 넣고 커밋·푸시하면 됩니다. 숨김 파일 `.gitignore`와 `.nojekyll`도 함께 포함하세요. 기존 저장소라면 그 저장소 폴더에 이 폴더의 내용물을 복사하세요.

```
index.html
style.css
game.js
config.js
state.js
geometry.js
assets-loader.js
layout.json
assets/
README.md
.gitignore
.nojekyll
```

이미지·좌표 경로가 모두 상대 경로이므로 저장소 이름이 붙는 하위 경로에서도 사용할 수 있습니다. GitHub에 파일을 올리는 것과 웹 호스팅을 활성화하는 것은 별도입니다.

## 로컬 실행

이 폴더에서 `python -m http.server 8000`을 실행하고 `http://localhost:8000`을 여세요. HTML 더블클릭은 ES 모듈과 JSON 로딩 때문에 지원하지 않습니다.

## 조작

- 책을 끌어 빈자리에 놓거나, 책과 빈자리를 차례로 누릅니다.
- 찬 자리에 드롭하면 오른쪽의 연속된 책들이 첫 빈칸까지 한 칸씩 밀립니다. 오른쪽 끝이 막히면 왼쪽 빈칸을 이용합니다.
- 빈자리에 드롭하면 그 책만 이동합니다. 책과 목적지를 차례로 누르는 보조 조작도 같은 규칙을 사용합니다.
- 책을 카트로 끌어 돌려놓을 수 있습니다.
- 같은 책이나 배경을 누르면 선택을 취소합니다.
- 모든 책을 올바르게 꽂으면 자동으로 클리어합니다.
- 진행 상태를 저장하며 ‘다시 시작’으로 초기화합니다.

## 설정 및 완료 연결

`config.js`에서 문구, gameId, storageKey, 정답 배열, 완료 연출 시간과 nextUrl을 수정하세요. gameId를 바꾸면 저장 키도 바꾸세요. 배치는 `layout.json`에서 수정합니다. idle_paws는 대기 손의 크기·위치, grip_paws는 잡는 손의 크기·위치입니다. cart_book_samples는 카트 위 책 배치이며, cart.foreground_clip_rects는 책 위에 겹쳐 그리는 카트 앞 테두리 영역입니다.

완료 연출 후 다음 이벤트를 한 번 발생시킵니다. 완료 상태를 복원할 때는 다시 발생시키지 않습니다.

```js
window.addEventListener('bookband:complete', ({ detail }) => {
  // detail: { gameId, status: 'complete', complete: true }
});
```

또는 `CONFIG.onGameComplete`에 함수를 지정합니다. nextUrl을 비워 두면 완료 화면에 머뭅니다.

## 에셋 및 검증

책은 새 PNG에서 만든 무손실 `assets/books-atlas-crisp-v2.webp`와 대응 JSON을 기본으로 로드합니다. 책등의 글씨·색상·투명도는 PNG와 동일하며 코드로 글씨를 덧쓰지 않습니다. 배경·카트·고양이 손은 품질 92의 WebP를 사용하며 원래 크기와 alpha를 유지합니다. 모든 PNG는 WebP 로드 실패 시에만 대체 로드합니다.

초기 이미지 다운로드 합계는 3,362,792바이트 → 1,171,420바이트로 약 65.2% 줄었습니다. 이 수치는 HTTP 헤더와 HTML·CSS·JS·JSON을 제외한 실제 요청 이미지 네 장의 원본 파일 크기입니다. 저장소에 PNG 대체 파일이 있어도 정상 로딩에서는 다운로드하지 않습니다.

| 이미지 | 이전 크기 | 적용 크기 |
| --- | ---: | ---: |
| 새 책 atlas | PNG 1,165,436 B | 무손실 WebP 797,270 B |
| 배경 | WebP 1,109,294 B | WebP 138,358 B |
| 카트 | WebP 420,278 B | WebP 88,002 B |
| 고양이 손 | WebP 667,784 B | WebP 147,790 B |

Canvas 내부 크기는 CSS 표시 크기 × DPR(1~3)입니다. 매 렌더링에서 좌표 변환을 초기화하고 책만 원본에서 고품질 축소합니다. 배경과 손의 기존 렌더링 방식은 유지합니다. 서가 책 밑면과 클릭·드롭 영역은 baseline 860에 맞췄습니다.

카트의 모든 책은 서가 공통 크기의 0.72배입니다. 눕힌 책은 같은 크기를 90도 회전하며, 더미의 빈자리는 화면 배치만 내려앉혀 채웁니다. 책 id와 저장 배열은 바꾸지 않습니다. 크림빛 실루엣은 카트 책의 조작 가능 여부를 나타내며 정답과 무관합니다. 빛 자체는 클릭되지 않고 앞쪽 금속 프레임은 책과 빛을 함께 가립니다.

360px·390px / DPR 1~3의 Native Canvas 렌더와 모의 터치 Pointer Events를 검증했습니다. 밀어 넣기, 카트 복귀, 취소, 저장 복원, 재시작, 자동 클리어를 검사했고 무작위 이동 30,000회에서 열 권의 중복·누락이 없었습니다. 실제 브라우저는 로컬 서버 연결 시간 초과로 검증하지 못했으며, 실기기 터치 검증도 아직 완료하지 못했습니다.

WebP 압축 적용 후 정상 로딩과 WebP 실패 시 PNG 대체 로딩에서 각각 50개 모의 입력 검사를 통과했습니다. 360px Canvas 렌더를 압축 전후로 비교했고, 책의 보이는 RGBA 픽셀 및 나머지 이미지의 alpha가 압축 전과 일치함을 확인했습니다.
